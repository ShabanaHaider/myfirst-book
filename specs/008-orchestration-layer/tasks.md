## Phase 4: User Story 2 - Prompt Construction with Context Management (Priority: P1)

### Goal
Implement proper prompt construction by combining user queries with retrieved chunks while managing token limits and context size.

### Independent Test Criteria
- Given a query with many relevant retrieved chunks that would exceed token limits, when the orchestration layer constructs the prompt, then the system selects and trims content to fit within token limits while preserving essential information
- Given a user query, when the orchestration layer combines it with retrieved chunks, then the resulting prompt is properly formatted for LLM consumption with clear context separation
